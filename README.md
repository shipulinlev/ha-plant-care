# Plant Care для Home Assistant

Custom integration для Home Assistant, которая помогает ухаживать за домашними и садовыми растениями: ведёт список растений по комнатам, запоминает поливы и подкормки и подсказывает, когда пора снова, с учётом температуры и влажности в комнате или погоды на улице.

> Статус: ранняя разработка, до v0.1.0. Прогресс ведётся в [PLAN.md](PLAN.md).

## Возможности

- **Растения в штатном UI HA.** Добавление, редактирование и удаление в «Настройки → Устройства и службы → Plant Care». Каждое растение становится отдельным устройством.
- **Комнаты.** Растение привязывается к существующей области (area) HA. Чтобы переместить растение, достаточно сменить область у устройства или вызвать сервис `plant_care.move`.
- **Умный план ухода.**
  - Нормы вида (температура, влажность воздуха и почвы) берутся из [OpenPlantbook](https://open.plantbook.io).
  - Интервал полива вычисляется по вашей истории поливов и корректируется по климату: в жару и сухом воздухе поливать нужно чаще, в прохладе реже.
  - Для комнатных растений используются датчики температуры и влажности в той же области.
  - Для сада и балкона используется погода (`weather.*`), дождь учитывается как полив.
  - Если у растения есть датчик влажности почвы, его показания приоритетнее.
  - Подкормка планируется по заданному интервалу с учётом сезона.

## Установка

### HACS (рекомендуется)
1. HACS → Integrations → ⋮ → Custom repositories → добавьте URL репозитория, категория *Integration*.
2. Установите **Plant Care** и перезапустите Home Assistant.

### Вручную
Скопируйте `custom_components/plant_care` в `<config>/custom_components/` и перезапустите Home Assistant.

**Требования:** Home Assistant 2026.7 или новее (точная минимальная версия будет зафиксирована к релизу).

## Настройка

1. Получите `client_id` и `client_secret` на [open.plantbook.io](https://open.plantbook.io) (раздел API).
2. «Настройки → Устройства и службы → Добавить интеграцию → Plant Care», введите ключи и при желании выберите погодную сущность для уличных растений.
3. В карточке интеграции нажмите **«Добавить растение»**: имя, вид (поиск по OpenPlantbook), комната или улица, область, опционально датчик влажности почвы, стартовый интервал полива и интервал подкормки.

## Сущности растения

| Сущность | Описание |
|---|---|
| `sensor.<растение>_next_watering` | когда следующий полив |
| `sensor.<растение>_next_feeding` | когда следующая подкормка |
| `sensor.<растение>_watering_status` / `_feeding_status` | `ok`, `soon`, `due`, `overdue` |
| `sensor.<растение>_last_watered` / `_last_fed` | последний уход |
| `binary_sensor.<растение>_needs_water` / `_needs_feeding` | пора ли поливать или подкармливать |
| `button.<растение>_water` / `_feed` | отметить «полил» или «подкормил» сейчас |

## Сервисы

| Сервис | Описание |
|---|---|
| `plant_care.water` | отметить полив (опционально `when` задним числом) |
| `plant_care.feed` | отметить подкормку |
| `plant_care.move` | переместить растение в другую область |
| `plant_care.refresh_species` | обновить данные вида из OpenPlantbook |

## Пример автоматизации

```yaml
alias: Напоминание о поливе
triggers:
  - trigger: state
    entity_id: binary_sensor.monstera_needs_water
    to: "on"
actions:
  - action: notify.mobile_app_phone
    data:
      message: "Пора полить монстеру 🌿"
```
